# Large language models predict which studies replicate

Code, data, and analysis materials for the manuscript "Large language models predict which studies replicate," currently under review.

**Author:** Bradley C. Love, EmpiriQal, Inc.

## Release status

This repository is currently private. All code, data files, and materials described below will be made fully open at the time of paper acceptance.

## Overview

This repository contains everything needed to reproduce the results and figures in the paper. It includes:

- **Code** for evaluating large language models on the replication-prediction task
- **Data files** from the SCORE project (Systematizing Confidence in Open Research and Evidence), covering the replicability of claims in the social and behavioral sciences
- **Plot commands** to recreate every figure in the paper
- **Simulation code** for the simulations reported in the paper

## Repository contents

```
.
├── code/          # Model evaluation and analysis code
├── data/          # Data files used from the SCORE project
├── figures/       # Plot commands to recreate the paper's figures
├── simulations/   # Code for the simulations
└── README.md
```

## Reproducing the results

1. Clone the repository.
2. Install the required dependencies (listed in the repository's requirements file).
3. Run the analysis code in `code/` to regenerate the results.
4. Run the plot commands in `figures/` to recreate the paper's figures.
5. Run the scripts in `simulations/` to reproduce the simulations.

## Data

The data files in `data/` come from the SCORE project. Please refer to the original SCORE project materials for full documentation of how the data were collected and for the terms under which they were released.
